# Свєта

Android-застосунок, який стежить за світлом: графіки відключень ДТЕК, реальний стан мережі через
EcoFlow і попередження «скоро вимкнуть» за дописами в Telegram.

- **Графік ДТЕК** для твоєї черги: сьогодні й завтра, з точністю до пів години. Регіони: Київ, Київська,
  Дніпропетровська та Одеська області.
- **EcoFlow DELTA Max**: мить, коли світло зникло чи з'явилось, поточний вольтаж у мережі, заряд і залишок часу.
- **Live Update** (Android 16+): закріплена картка з прогресом до наступного перемикання, у рядку стану — вольтаж,
  а коли світла немає — на вибір відлік до увімкнення, заряд EcoFlow або на скільки його вистачить.
  На старіших версіях — звичайна постійна картка з тим самим вмістом. Картку можна сховати: кнопкою «Сховати» на ній —
  на час, обраний у налаштуваннях (30 хв – 8 год), або до наступної події (світло вимкнули чи увімкнули, екстрені
  відключення, прогноз за сусідами); вимикачем у налаштуваннях — назовсім. Моніторинг і сповіщення
  працюють далі, а в шторці лишається тихий рядок (без нього система не дозволяє сервісу працювати), який на
  Android 13+ можна просто змахнути.
- **Сповіщення за графіком** — станція для них не потрібна:
  - нагадування перед кожним вимкненням та увімкненням (за 5–60 хв, на вибір) і в сам момент перемикання;
  - новий графік на завтра, зміна графіка або скасування відключень на день;
  - екстрені відключення на Київщині та їх скасування — за дописами офіційного каналу [@dtek_ua](https://t.me/s/dtek_ua).
    Поки вони діють, застосунок чесно показує «графік не діє» і не нагадує про години, яких ніхто не дотримується.
- **Прогноз за сусідніми лініями**: кожна сусідня лінія додається зі своїм публічним Telegram-каналом. Застосунок
  читає ці канали й попереджає, коли вимкнули лінії, після яких зазвичай вимикають твою. Якщо канал лише про одну
  лінію, ключові слова не потрібні; якщо про кілька — лінію впізнають за ними. Затримку (типово 5–20 хв) застосунок
  з часом вивчає сам.
- Material 3 Expressive, динамічні кольори, мова інтерфейсу — українська.

## Збірка

Потрібні JDK 17+ та Android SDK з платформою 37.

```bash
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease      # мінімізована збірка, підписана debug-ключем
adb install -r app/build/outputs/apk/release/app-release.apk
```

## Перевірка

```bash
./gradlew testDebugUnitTest                                              # юніт-тести
./gradlew testDebugUnitTest -Psveta.live=true --tests "*LiveSourcesTest" # живі запити до джерел
./gradlew lintDebug
```

У debug-збірці в «Налаштування → Діагностика» є кнопки «Зникло» / «З'явилось», які імітують зміну напруги —
зручно, щоб подивитись на сповіщення й живу картку, не чекаючи відключення. Поруч — зразки сповіщень про екстрені
відключення й нагадування за графіком. Там само видно сирі параметри станції.

## Звідки дані

| Що | Джерело | Примітка |
|---|---|---|
| Графік | [outage-data-ua](https://github.com/Baskerville42/outage-data-ua), файли `data/<регіон>.json` | Сайти ДТЕК закриті захистом від ботів і звичайному HTTP-клієнту віддають порожню сторінку. Дзеркало знімає ті самі дані headless-браузером. Джерело сховане за інтерфейсом `DtekSource`. |
| Стан мережі | Приватний API застосунку EcoFlow: вхід за e-mail і паролем, далі MQTT | Неофіційний, може зламатись після оновлень EcoFlow. Протокол узято з [hassio-ecoflow-cloud](https://github.com/tolwi/hassio-ecoflow-cloud). Вольтаж — параметр `inv.acInVol`. |
| Дописи | Веб-перегляд `https://t.me/s/<канал>` | Лише публічні канали, опитування раз на 30 с. Канал у кожної лінії свій; лінії зі спільним каналом читаються одним запитом. |
| Екстрені відключення | Той самий веб-перегляд каналу `@dtek_ua` | У JSON дзеркала такої ознаки немає, а ДТЕК пише про запровадження й скасування саме тут. Лише для Київської області: допис розбирається за згадками «Київщина» / «Київська область», в інших регіонах ця перевірка вимкнена. Опитування раз на 2 хв; допис читається повторно, бо скасування часто дописують у той самий допис як «UPD: …». |

Регіони описані в `DtekRegion`; кожен відповідає файлу дзеркала й сайту мережі:

| Регіон | Файл | Сайт |
|---|---|---|
| Київ | `kyiv.json` | dtek-kem.com.ua |
| Київська обл. | `kyiv-region.json` | dtek-krem.com.ua |
| Дніпропетровська обл. | `dnipro.json` | dtek-dnem.com.ua |
| Одеська обл. | `odesa.json` | dtek-oem.com.ua |

Перелік черг береться з самого графіка, бо в регіонах він різний: у Києві шістдесят черг, на Дніпропетровщині
окрім 1.1–6.2 є черги ЦЕК. Кеш і ETag у кожного регіону свої, тож після повернення до попереднього регіону
його графік видно одразу, а перемикання не видається за «зміну графіка».

Пароль EcoFlow зберігається тільки на пристрої, зашифрований ключем з Android Keystore, і надсилається лише на сервер EcoFlow.

## Як влаштовано

```
domain/    чиста логіка без Android: Timeline, PowerMonitor, PostMatcher, PredictionEngine,
           EmergencyMatcher/Tracker, PlannedAlerts, Texts
data/      dtek (дзеркало + кеш), ecoflow (логін, MQTT), telegram (парсер, екстрені), store (налаштування, історія)
service/   MonitorService (foreground), Live Update, Alerts (усі сповіщення про події), будильник нагадувань,
           автозапуск, годинний WorkManager
ui/        Compose: Зараз, Графік, Прогноз, Налаштування, онбординг
```

- `PowerMonitor` вважає світло наявним, якщо вхідна напруга вища за поріг (типово 150 В), і повідомляє про зміну лише
  після 5 с стабільного стану. Якщо станція замовкла, стан стає «невідомо» — або «ймовірно вимкнули», якщо в
  налаштуваннях увімкнено «Станція офлайн = світла немає».
- `PredictionEngine` тримає прогноз, доки світло справді не зникне (збіг — затримка запам'ятовується) або не мине
  подвійне вікно (промах). Після трьох збігів типове вікно замінюється виміряним.

- `EmergencyMatcher` шукає в дописі останнє твердження про Київську область («запроваджені», «тривають»,
  «скасовано», «повертаємось до графіків»); дописи лише про місто Київ чи інші області ігноруються.
  `EmergencyTracker` оголошує лише свіжі зміни (до 3 год) і вважає екстрені завершеними, якщо їх ніхто не
  підтверджував 36 год — скасування пишуть не завжди.
- `PlannedAlerts` бере перемикання лише з опублікованого графіка (тижневий шаблон «можливих» відключень не рахується).
  Нагадування ставляться через `AlarmManager`, тож приходять і без фонового моніторингу. Сповіщення «у сам момент»
  пропускається, якщо EcoFlow бачить мережу: тоді про справжнє перемикання повідомить станція.
- Усі події проходять через `Alerts`, хто б їх не помітив — сервіс, годинний воркер, будильник чи відкритий застосунок.

## Обмеження

- Лише регіони, які є в дзеркалі: ДТЕК Донецькі електромережі воно не знімає, тож їх немає і тут.
- Лише DELTA Max (інші моделі EcoFlow мають інші назви параметрів).
- Якщо роутер не живиться від станції, вона зникає з мережі разом зі світлом — тоді точний вольтаж недоступний,
  а відключення визначається за зникненням станції.
- Правила, за якими система закріплює Live Update, виробник телефона може змінювати.
- Екстрені відключення ДТЕК часто запроваджує для окремих районів області; застосунок не знає твого району й
  сповіщає про будь-які в області, цитуючи допис.
- На Android 14+ точні будильники вимкнено за замовчуванням: без дозволу («Налаштування → Сповіщення → Дозволити
  точний час») нагадування може запізнитись, якщо фоновий моніторинг не працює.
- Без фонового моніторингу графік та екстрені перевіряються раз на годину.
